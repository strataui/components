# Strata Components (`strataui/components`)

Official accessible UI component library, ARIA primitives, and vector icon set for the [Strata](https://github.com/strataui/strata) pure-Rust frontend framework.

## Crates

- **`strata-icons`** — Vector icon catalog (`Icons::*`) for Strata UI applications.
- **`strata-aria`** — WAI-ARIA headless behavioral state machines (Dialog, Menu, Tabs, Select, Combobox, Popover, Accordion, Focus Trap).
- **`strata-components`** — Production Radix/shadcn-tier styled components built on `strata-ui`, `strata-aria`, and `strata-icons`.

## Usage

```toml
[dependencies]
strata-ui = "0.1"
strata-components = "0.1"
strata-icons = "0.1"
```
